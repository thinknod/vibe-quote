# 견적 한 장: 기획서 v1

작성 2026-11-18. 배포 실습 앱 5번. 대표 요청: 지역 기업 2세들이 함께 듣는 자리에서 "바이브코딩이 우리 사업에 쓸 만하다"고 느끼게 할 샘플.

## 한 줄

> 거래처가 휴대폰으로 품목과 수량을 고르면 견적 금액과 납기가 바로 나오고, 견적서 한 장을 인쇄하거나 PDF로 저장하고, 링크로 보내는 웹. data.js의 단가표만 바꾸면 우리 회사 견적기가 된다.

## 왜 이것인가

- 듣는 사람이 회사를 물려받을 사람이다. 제조, 유통, 납품 회사라면 견적 문의에 전화와 엑셀로 답하는 일이 거의 다 있다. 돌림판, 초대장보다 '내 회사 일'로 바로 읽힌다
- 빨리 답하는 것이 돈이 된다는 장면이 있다: 수업의 가상 회사 새벽금속 기록에서 새 거래처에 이틀 안에 답하면 13.9%, 닷새 넘으면 3.7%가 수주됐다(class 데이터 강의의 가상 데이터, 실제 통계 아님)
- 현장에서 내 것으로 바뀐다: 참여자가 자기 회사 품목 셋만 넣어도 자기 견적기. 발표 때 서로의 견적기를 열어 본다

## 누가, 언제

| 사용자 | 순간 | 바라는 것 |
|---|---|---|
| 거래처 담당자(받는 사람) | 발주 전, 대략 얼마인지 알고 싶을 때 | 전화 없이 금액과 납기를 1분 안에, 상사에게 올릴 견적서 한 장 |
| 우리 회사 영업(만드는 사람) | 같은 질문에 하루 몇 번씩 답할 때 | 단가표를 한 번 넣어 두고 링크만 보내기, 받은 견적 링크로 같은 내용 확인 |

## 1분 흐름

```
품목 카드 고르기 → 재질, 표면 처리, 수량, 납기(보통/빠름) → [견적에 담기]
   → 담은 줄들: 단가, 수량 할인, 금액 → 합계(공급가액, 부가세, 합계), 예상 납기, 유효 기간
   → [견적서 보기] 견적번호, 날짜, 받는 회사(선택), 표, 합계, 안내 → [인쇄, PDF 저장] [링크 복사] [보내기]
받은 링크로 열면: '받은 견적' 표시, 같은 견적서. [이 견적으로 다시 고르기]
```

| 4 담은 견적 | 줄마다 품목과 옵션, 단가, 수량, 금액, 빼기. 합계 칸 |
| 5 견적서 | 인쇄용 한 장(A4). 공급자 정보, 표, 합계, 안내 문구, 유효 기간 |

- PC 1024px 이상: 왼쪽에 품목과 옵션, 오른쪽에 붙어 따라오는 담은 견적과 합계
- 휴대폰: 한 줄로 쌓고, 아래 고정 막대에 합계와 '견적서 보기'

## 계산 (한 함수로 고정)

```
단가 = 기준 단가 × 재질 배수 × (1 + 표면 처리 비율)   (10원 단위 올림)
줄 금액 = 단가 × 수량 × (1 - 수량 구간 할인)        구간: 100개 3%, 500개 7%, 1000개 10%
빠른 납기 = 줄 금액 × 1.15, 납기 일수 40% 줄임(올림)
공급가액 = 줄 금액 합,  부가세 = 공급가액 × 10% (원 단위 내림),  합계 = 공급가액 + 부가세
예상 납기 = 담은 줄 중 가장 긴 납기(영업일)
```

| 품목, 옵션, 수량 할인, 빠른 납기, 부가세 | 도면 파일 첨부(서버 필요) | 결제, 주문 확정 |
| 견적서 인쇄와 PDF(브라우저 인쇄) | 견적 요청을 메일이나 폼으로 받기(rsvp처럼 링크) | 실제 사업자 정보, 개인 연락처 |
| 링크로 견적 보내기(주소에 품목과 수량만) | 품목 사진 | 거래처 명단 저장 |
| 이 브라우저에 담은 견적 기억 | 엑셀 단가표 붙여 넣기 | 서버 저장 |
